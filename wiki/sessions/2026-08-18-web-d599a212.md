# 세션 web-d599a212 (2026-08-18)

## 질문

Aws k8s에 있는 nexus-lake와 azure에 있는 sliver 데이터가 어느정도 일치하는지 확인해줘

## 결론

**결론:** 현재 제공된 도구만으로는 AWS Nexus Lake와 Azure의 **Silver 데이터 일치율을 직접 계산할 수 없습니다.**

- 현재 Kubernetes 조회 연결은 **Azure dev(`azure-uae-gsp`)**뿐이며 AWS dev 데이터에 접근할 수 없습니다.
- Kubernetes 도구는 워크로드·로그 조회용이고, Trino에서 레코드 수·키·해시를 비교하는 SQL 도구는 제공되지 않았습니다.
- 이전 Azure 관찰에서는 Bronze 적재가 Azure DFS의 `409 EndpointUnsupportedAccountFeatures` 오류로 반복 실패했습니다. 따라서 해당 기간의 Azure Silver 데이터는 AWS보다 누락됐을 가능성이 있습니다.
- 정확한 비교에는 양쪽 Trino에서 동일한 `catalog.schema.table`, 기간, 테넌트 및 고유키를 기준으로 `COUNT`, 키 집합, 컬럼별 null 수, 집계값, 행 해시를 비교해야 합니다.
- 비교 대상을 지정해 주세요: **테넌트, Silver 테이블/리소스, 시간 범위, 일치 판정 키**. 이후 AWS·Azure 양쪽 Trino를 조회할 수 있는 data-analyst 세션에서 일치율과 누락/불일치 건수를 계산해야 합니다.

Secret이나 인증정보는 조회 범위 밖입니다.
